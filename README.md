## 真实评价和四个容易踩的坑

中文评测里夸得最多的是更新勤快和免费版没被阉割，开源这一点不用夸，本来就是。GitHub 上的提交一直在动，2026 年初还发了 v1.16.9，一个个人维护的项目能做到这个频率不容易。日常用下来最省事的是右键菜单直接「在沙盒中运行」，用完清空沙盒，主系统干干净净。

坑主要在授权条款上，功能本身反倒没什么好挑的。

到期机制值得单独说。个人证书过期之后，官方在你过期之后编译的新版本里，那些高级功能就不再解锁了，只有过期之前的老版本还保持解锁状态。也就是说 1 年版到期，不是简单续个费那么轻松，想用新版就得重新买。

加密包另算这件事前面提过，官方文档写明了 Contributor 和 Eternal 这两类证书默认带全部 Advanced 选项，但数码荔枝的档位命名跟官网不完全对应，买之前对一下商品说明。

上手门槛也得有心理准备。Sandboxie Plus 的设置项确实多，第一次打开会有点懵，中文评测里也提到要适应一阵。好在日常只用右键「在沙盒中运行」这一个动作，不去动高级设置就不会出问题。

商用授权是最容易被忽略的一条。公司里给同事装、学校机房用，都属于需要 Business Certificate 的场景，个人版授权不覆盖，别等出了问题才发现。
